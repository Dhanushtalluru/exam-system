# ExamPortal Frontend (React + Vite)
Requires Node 18+ and the backend running at http://localhost:8080.
```bash
cd frontend
npm install        # once, installs dependencies
npm run dev        # starts http://localhost:5173
```
API address is set in `frontend/.env` (`VITE_API_URL=http://localhost:8080/api`). Restart `npm run dev` after editing it.
